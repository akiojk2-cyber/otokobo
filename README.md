# OTO KOBO（おと工房）

こどもが「ろくおん → えんそう → きょく」で音楽をつくるWebアプリ。HTML1枚で動きます。

- ろくおん：マイクを おすと 4つ かぞえて ろくおん（レベルメーターつき）。こえや ものおとが がっきになる
- えんそう：いたを たたいて あそぶ。⭐ を おすと 4つ かぞえて 2しょうせつを テープに ろくおん
- きょく：テープ（さいだい12ほん）を かさねて「せーの！」で いっしょに さいせい。WAVで ほぞん
- こえの へんしん：とった おとを ロボット・ねずみ・くま・やまびこ・さかさまに へんしん
- つづきから：つくった おとと テープは この たんまつの なかに のこるので、つぎに ひらいても つづきから あそべます（「？」→「はじめから つくる」で ぜんぶ けせます）
- ことば：にほんご／English／中文／한국어／Українська。各画面の「？」で つかいかたを みられます

マイクを使うため、https（GitHub Pages）で開いてください。

## セキュリティとプライバシー

- 録音した音・作った曲は、この端末のブラウザ（IndexedDB）の中だけに保存し、どこにも送信しません（外部への通信なし）
- 外部のフォントやスクリプトは読み込みません。CSP（コンテンツセキュリティポリシー）で、このページ自身のスクリプト以外の実行と外部通信をすべて禁止しています
- マイクは録音画面にいる間だけ使い、画面を離れたとき・アプリを切り替えたとき・60秒使わなかったときに自動で切ります
- ほかのサイトに埋め込まれた状態ではマイクを使えません
